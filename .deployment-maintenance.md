# 🔧 Поддержка скриптов развертывания

## Автоматическое обновление при изменении зависимостей

При изменении `requirements.txt` или других зависимостей необходимо обновить скрипты развертывания.

## Чеклист обновления

### При изменении `requirements.txt`:

- [ ] Проверить что `deploy.sh` использует `requirements.txt` (уже автоматически)
- [ ] Обновить минимальную версию Python в `deploy.sh` если нужно
- [ ] Проверить что все новые зависимости совместимы
- [ ] Обновить документацию в `README.md` если нужно

### При изменении структуры проекта:

- [ ] Обновить пути в `deploy.sh` если изменились директории
- [ ] Обновить `start.sh` если изменился `main.py` или структура
- [ ] Обновить `QUICK_START.md` если изменился процесс

### При изменении конфигурации:

- [ ] Обновить шаблон `.env` в `deploy.sh`
- [ ] Обновить `interactive_env_setup()` если добавились новые параметры
- [ ] Обновить документацию по конфигурации

## Автоматическая проверка

Запустите скрипт проверки:

```bash
./scripts/check-deployment-sync.sh
```

Этот скрипт проверит:
- Соответствие зависимостей в requirements.txt и deploy.sh
- Наличие всех необходимых файлов
- Корректность путей в скриптах

## Процесс обновления

1. **Изменить зависимости:**
   ```bash
   # Отредактировать requirements.txt
   nano requirements.txt
   ```

2. **Проверить синхронизацию:**
   ```bash
   ./scripts/check-deployment-sync.sh
   ```

3. **Обновить deploy.sh (если нужно):**
   - Проверить минимальную версию Python
   - Обновить шаблон .env если добавились новые параметры
   - Обновить комментарии

4. **Протестировать:**
   ```bash
   # В тестовой директории
   ./deploy.sh
   ```

5. **Закоммитить изменения:**
   ```bash
   git add requirements.txt deploy.sh
   git commit -m "Update dependencies and deployment scripts"
   ```

## Важные файлы для поддержки

- `requirements.txt` - Python зависимости
- `deploy.sh` - Скрипт развертывания
- `start.sh` - Скрипт запуска
- `stop.sh` - Скрипт остановки
- `status.sh` - Скрипт статуса
- `config.py` - Конфигурация приложения
- `.env.example` - Шаблон конфигурации
